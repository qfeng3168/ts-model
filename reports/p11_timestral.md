# P11：Timestral-209M 零样本探针（2026-11-11 定案）

对象：mistralai/Timestral-209M 零样本预测。输入 = 331 个调仓日 ×
时点成分股 = 99,141 条序列（t 前 512 日收盘），预测未来 5 日，
取中位数隐含收益作排序信号。评估口径与 P9/P10 一致：PIT 宇宙、
成交标签 close(t+1)→close(t+6)（dataset_pit2 的 fwd_ret_5）。
预注册裁决：年均 RankIC < 0.015 关线。

工程插曲（四版才跑通，均与模型无关）：v1 数据集挂载路径写死 →
v2 spawn 的 lambda 不可 pickle → v3 CUDA 张量直接转 numpy 被拒 →
v4 跑通，双卡 305 秒出 99,141 条。另注：落盘的每格是 5 步完整路径，
评估取最后一步（5 日点）。

## 结果

| 年 | RankIC |
|---|---|
| 2020 | 0.0072 |
| 2021 | −0.0020 |
| 2022 | 0.0344 |
| 2023 | 0.0331 |
| 2024 | 0.0370 |
| 2025 | −0.0025 |
| 2026 | −0.0081 |
| **年均** | **0.0142** |

- 组合（top20% 等权、旧固定成本口径）：年化 **−21.8%**、Sharpe
  −1.09、回撤 −37.1%——IC 微正但头部选股是灾难。
- 对照：PIT D6 0.0303、Kronos 零样本 0.0118。Timestral 略高于
  Kronos、只有 D6 的一半，且 2025/2026 转负，不稳定。

## 裁决

**0.0142 < 0.015，按预注册关线**：Timestral 不作收益排序器，
与 Kronos 同判。通用时序基础模型的零样本点预测不迁移到 A 股
截面排序，这是第二次实证（两个模型、同一结论）。

## 唯一的副产品：分位宽度是真波动信号

q90−q10 宽度与事后 5 日 |收益| 的日截面 Spearman 均值 = **0.3306**。
模型不会排序收益，但会估波动。若后续要用，方向是把宽度（或下行
分位）作风险特征喂 GBDT / 组合层，而不是当 alpha。是否开这条线
待用户拍板，本报告不自动推进。
